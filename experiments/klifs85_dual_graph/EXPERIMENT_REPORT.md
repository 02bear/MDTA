# KLIFS-85 / BRICS 第二粒度 Stage-1 验证报告

## 结论

当前第二粒度实现未通过进入全阶段训练的门槛。真实 KLIFS 分支在 seed 42、43、44 上均由 early stopping 选择 epoch 0（冻结 P13D 原预测），即 0/3 个种子改善主验证指标。按预先约定，不进行端到端解冻。

本结论限定于当前实现：冻结 P13D 表示上的 BRICS 片段图、KLIFS-85 口袋图、双向跨图注意力和残差融合。它不能推出“KLIFS 信息在任何模型中都无效”。

## 数据预处理

- 服务器缓存：`/data1/ztx/MyModel-MDTA/experiments/klifs85_dual_graph/data/fold1/entity_graphs.pt`
- 服务器审计：`/data1/ztx/MyModel-MDTA/experiments/klifs85_dual_graph/data/fold1/cache_audit.json`
- 药物：由冻结的三层 Drug3DEGNN 产生 128 维显式氢原子表示；按 BRICS 可断裂键划分片段；每个片段对原子表示做 mean/max 聚合得到 256 维节点；断裂键连接对应片段，边特征 7 维。
- 蛋白：由冻结的三层 Protein3DEGNN 产生 128 维残基表示；按 KLIFS 映射选择标准 85 位点，并拼接 1024 维 ProtT5 表示；采用 Cα kNN-8 和相邻主链边，边特征 19 维。
- 审计统计：68 个药物、442 个蛋白；423/442 个蛋白具有可接受 KLIFS 映射；药物片段数 3–13，均值 7.5882；有效 KLIFS 位点数均值 81.0498/85。

## 模型和防护

- 全局分支固定为 P13D 的 256 维 pair feature 与冻结预测。
- 药物片段图和蛋白口袋图各经过两层 GATv2；之后进行双向 cross-attention 和注意力池化。
- 将 128 维局部表示与 256 维全局表示拼接，MLP 预测对冻结 P13D 的残差。
- 残差输出层零初始化，所以 epoch 0 与 P13D 完全一致；三种子最大绝对差均为 0。
- 仅使用 train/validation；脚本未物化或计算 test split。

## 结果

P13D 验证基线：MSE 0.489465，RMSE 0.699618，MAE 0.431438，CI 0.788562，Rm² 0.341028。

| 条件 | seed | early-stop 最佳轮次 | 训练后最低 val MSE | 相对基线 MSE 变化 | 对应 CI | 对应 Rm² |
|---|---:|---:|---:|---:|---:|---:|
| real KLIFS | 42 | 0 | 0.500496 (epoch 1) | +2.254% | 0.788831 | 0.340047 |
| real KLIFS | 43 | 0 | 0.499631 (epoch 3) | +2.077% | 0.786892 | 0.339534 |
| real KLIFS | 44 | 0 | 0.494294 (epoch 1) | +0.987% | 0.789103 | 0.341170 |
| shuffled protein | 42 | 0 | 0.499936 (epoch 6) | +2.139% | 0.783435 | 0.342500 |
| self-loop only | 42 | 0 | 0.500482 (epoch 1) | +2.251% | 0.788897 | 0.340069 |

所有保存的最佳模型都回退到 epoch 0，因此正式 best 指标与 P13D 完全相同，`relative_mse_gain = 0`。结果中的 drug bootstrap 也因此全为 0；这只是安全回退的结果，不能当作第二份独立统计证据。

## 因果判读

1. **没有跨种子收益。** 真实分支 0/3 改善 MSE，未达到至少 2/3 种子改善的门槛。
2. **没有正确配对特异性。** seed 42 中，打乱蛋白身份的最低 MSE 反而略好于真实配对；仅自环与真实图几乎相同。这不支持收益来自正确的 KLIFS 口袋、片段拓扑或二者交互。
3. **训练集可拟合但药物冷启动不可泛化。** seed 42 的训练 MSE 从约 0.219 降到 0.181，而验证 MSE由首轮 0.5005 最终升到约 0.5144，属于明显的残差过拟合。
4. **标量亲和力监督不能唯一确定局部配对。** 每个复合物只有一个 affinity 标签，跨图注意力可以通过药物/蛋白身份相关性降低训练误差，不必学会真实片段—口袋对应关系。
5. **新增信息相对有限。** 两路局部节点仍以 P13D 已使用的冻结三维编码器为基础；BRICS/KLIFS 主要重新组织已有表示。它增加了参数和拟合自由度，但没有提供真实接触或姿态标签来约束跨图注意力。

## 决策

- 当前不进行全阶段解冻；否则更可能放大已经观察到的训练集拟合和验证集退化。
- 保留代码、缓存和完整结果作为否定性实验，不删除、不覆盖。
- 若继续第二粒度路线，下一次实验必须先引入能区分真实局部配对与打乱配对的独立监督或预训练目标，再重复相同的 real/shuffled/self-loop 门控验证；不建议仅靠调学习率、加层数或直接解冻来挽救当前结构。
